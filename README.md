# ElevateU

Personalized Career Development Platform for Students.

## Stack
- Frontend: React.js + Vite
- Backend: Node.js + Express.js
- Database: MongoDB
- Authentication: JWT
- API style: REST

## Planned modules
1. Authentication
2. Student Profile
3. Skills & Proficiency
4. Career Path Selection
5. Skill Gap Analysis
6. Career Readiness Score
7. Project-to-Skill Mapping
8. Personalized Learning Roadmap
9. Project Recommendations
10. Certificates
11. GitHub Integration
12. Resume Builder
13. Public Portfolio
14. Admin Module

## Start
Open two VS Code terminals.

### Backend
cd server
npm install
npm run dev

### Frontend
cd client
npm install
npm run dev
